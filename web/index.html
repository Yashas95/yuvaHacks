How to read a report

  • Simple view gives a plain-English answer per file. Expert view shows every measurement. Switch any time.
  • Ask the assistant on any report: “Is this AI-generated?”, “Where exactly?”, “What should I do?”. It answers only from the evidence, offline.
  • Score is an indicator, not a verdict. Each finding lists what, where, why and what else could explain it.
  • Families, not votes. Correlated detectors don't stack; ML-only findings are capped below "Moderate".
  • Source trace. Files are hashed at intake and re-verified after analysis.

Chrome extension

Check a photo, post or reel on Instagram or any site without downloading it. Right-click it → Check with TruthLens.

Download extension (.zip)
  1. Unzip the file.
  2. Open chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and pick the unzipped truthlens-extension folder.
  4. Pin it, then right-click any post → Check with TruthLens. It is already set to use this server.
